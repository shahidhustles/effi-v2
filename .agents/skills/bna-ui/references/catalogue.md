# Catalogue

Install any of these with `npx bna-ui add <name>`. For props and source, run
`npx bna-ui info <name> --json`.

## Components

- `accordion` — A vertically stacked set of interactive headings that each reveal a section of content.
- `action-sheet` — A native-feeling action sheet component that provides a menu of options triggered from the bottom of the screen.
- `alert` — Display important messages to users with both visual inline alerts and native system alerts.
- `alert-dialog` — A modal dialog that interrupts the user with important content and expects a response.
- `audio-player` — A feature-rich audio player component with waveform visualization, playback controls, and seeking capabilities for music, podcasts, and voice recordings.
- `audio-recorder` — A comprehensive audio recording component with real-time waveform visualization, quality settings, and built-in playback capabilities.
- `audio-waveform` — A customizable audio waveform visualization component with playback progress and interactive seeking capabilities.
- `avatar` — An image element with a fallback for representing the user.
- `avoid-keyboard` — A component that automatically adjusts its height to avoid keyboard overlap with smooth animations and cross-platform support.
- `badge` — A small status descriptor for UI elements.
- `bottom-sheet` — A modal sheet component that slides up from the bottom with gesture support and snap points.
- `button` — A versatile button component with multiple variants, sizes, and interactive animations.
- `camera` — A powerful camera component with advanced features like zoom, timer, torch, and video recording.
- `camera-preview` — A comprehensive camera component with capture, preview, and media management capabilities.
- `card` — Displays a card with header, content, and footer.
- `carousel` — A flexible carousel component with support for auto-play, indicators, arrows, and custom layouts.
- `checkbox` — A control that allows the user to toggle between checked and not checked states.
- `collapsible` — An interactive component which can be expanded/collapsed to show and hide content.
- `color-picker` — A color picker component with HSV color space selection and swatch display.
- `combobox` — A searchable dropdown component that combines an input with a list of options.
- `date-picker` — A customizable date and time picker component with bottom sheet UI.
- `file-picker` — A customizable file picker component with validation, preview, and multiple file support.
- `gallery` — A responsive image gallery component with fullscreen viewing, zoom, and gesture support.
- `hello-wave` — An animated waving hand emoji component with smooth rotation animation.
- `icon` — A themed icon component with support for Lucide React Native icons.
- `image` — A responsive image component with loading states, error handling, and flexible styling options.
- `input` — A styled text input component with label, validation, icons, and grouped layouts.
- `input-otp` — A secure input component for one-time passwords and verification codes.
- `link` — A navigation component that handles both internal and external links with customizable browser behavior.
- `media-picker` — A versatile component for selecting images and videos from device gallery or camera with preview capabilities.
- `mode-toggle` — An animated button component for switching between light and dark themes.
- `onboarding` — A customizable multi-step onboarding flow with smooth animations and gesture support.
- `parallax-scrollview` — A scroll view with parallax header effect that transforms as the user scrolls.
- `picker` — A customizable dropdown picker component with search, sections, and multiple selection support.
- `popover` — A contextual overlay that displays rich content triggered by user interaction.
- `progress` — A progress bar component to show completion status with optional interactivity.
- `radio` — A set of checkable buttons—known as radio buttons—where no more than one of the buttons can be checked at a time.
- `scroll-view` — A scrollable view component that allows content to be scrolled when it exceeds the container size.
- `searchbar` — A customizable search input with debouncing, loading states, and suggestions.
- `separator` — Visually or semantically separates content.
- `share` — A button component for sharing content across platforms with native share functionality.
- `sheet` — A modal component that slides in from the side of the screen, commonly used for navigation menus, filters, and detail views.
- `skeleton` — A placeholder component to show a loading state while content is being fetched.
- `spinner` — A loading indicator component with multiple variants and customization options.
- `switch` — A control that allows the user to toggle between checked and not checked states.
- `table` — A flexible data table component with sorting, filtering, pagination, and search functionality.
- `tabs` — A swipeable, animated tabs component with support for scrollable tab lists and gesture-driven content switching.
- `text` — A foundational View component with transparent background and ref forwarding support.
- `toast` — A succinct message that is displayed temporarily with Dynamic Island animation inspired by iOS.
- `toggle` — A two-state button that can be either on or off.
- `video` — A video player component with custom controls, gestures, and subtitle support.
- `view` — A foundational View component with transparent background and ref forwarding support.

- `area-chart` — A customizable area chart component with gradient fills and smooth animations.

- `heatmap-chart` — A customizable heatmap chart component with smooth animations and flexible color scaling for visualizing matrix data.
- `line-chart` — A customizable line chart component with animations, interactions, and gradient fills.
- `pie-chart` — A customizable pie chart component with smooth animations and flexible styling.
- `polar-area-chart` — A customizable polar area chart component with smooth animations and flexible styling for displaying radial data.
- `progress-ring-chart` — A customizable circular progress ring component with smooth animations and flexible styling.
- `radar-chart` — A customizable radar chart component with smooth animations and flexible styling for displaying multi-dimensional data.
- `radial-bar-chart` — A customizable radial bar chart component with smooth animations, gradient support, and center value display.
- `scatter-chart` — A customizable scatter plot component with smooth animations and flexible styling for visualizing data relationships.
- `stacked-area-chart` — A customizable stacked area chart component with smooth animations and gradient fills for visualizing multiple data series over time.
- `stacked-bar-chart` — A customizable stacked bar chart component with smooth animations, support for both horizontal and vertical layouts, and flexible styling.
- `treemap-chart` — A customizable treemap chart component with hierarchical data visualization, smooth animations, and flexible styling using the squarified treemap algorithm.

## Hooks

- `useBottomTabOverflow` — useBottomTabOverflow
- `useColor` — useColor
- `useColorScheme` — useColorScheme
- `useHaptics` — Semantic haptic feedback that routes each intent to the right native API per platform — performAndroidHapticsAsync on Android rather than the Vibrator-simulated impact APIs Expo discourages.
- `useKeyboardHeight` — A React Native hook that tracks keyboard visibility, height, and animation duration with cross-platform support and screen rotation handling
